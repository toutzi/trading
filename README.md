# devteam — auth vertical slice (v1)

One source of truth, feature branches, reviewer as merge gate.

## Layout
- `contracts/auth-v1.yaml` — OpenAPI contract, **generated by the backend**, never hand-edited.
- `backend/` — FastAPI app, Pydantic schemas, Alembic migrations, pytest suite.
- `frontend/` — React app; typed client generated from the contract.

## Regenerate the contract (backend)
```sh
backend/scripts/export_openapi.sh   # -> contracts/auth-v1.yaml
```

## Run the backend test suite
```sh
cd backend && python -m pytest
```

## Migration + seed (local dev)
```sh
cd backend && alembic upgrade head && python seed.py
```

## Drift gate (reviewer)
1. `backend/scripts/export_openapi.sh` then `git diff contracts/` — zero diff = no contract drift.
2. `cd backend && python -m pytest` — green.
